# Prompts para gerar imagens do Anabol for Agents

Gere as 3 imagens abaixo. Salve como:
- cover.jpg (capa do projeto / README)
- slide.jpg (slide de apresentação)
- icon.png (ícone / logo do projeto)

Depois deixem os arquivos em /tmp/ (ou me envie) para eu subir.

---

## 1. cover.jpg — Capa do projeto (1200x800)
Estilo: flat design moderno, minimalista, paleta azul (#2563eb) e branco.
Composição: no centro, uma estrutura de segmentos/camadas de habilidades (código, IA, testes, documentos) fundindo-se em uma única coluna ou nó central. Linha de texto destaque: "Anabol for Agents". Subtítulo: "Fuse skills, don't accumulate them.". No fundo, padrão sutil de circuitos/linhas finas. Nenhum texto pequeno ilegível. Use fonte clean, sans-serif.

## 2. slide.jpg — Slide de apresentação (1600x900)
Estilo: apresentação de negócio/tech, paleta azul claro (#dbeafe) e azul médio (#3b82f6).
Composição: à esquerda, uma ilustração de peças/puzzling de habilidades (segmentos coloridos) se encaixando em um núcleo central. À direita, espaço vazio para título. Texto grande: "Anabol for Agents". Subtítulo: "Fuse skills, don't accumulate them.". Design limpo, sem texto poluído.

## 3. icon.png — Ícone / logo (256x256, transparente)
Estilo: flat icon, azul (#1e40af) sobre fundo transparente/ branco muito leve.
Composição: um símbolo de rede/brain feito de pequenos símbolos de código, agente e livro, se conectando. Abaixo, texto curto "ANABOL FOR AGENTS" em fonte bold, legível até em tamanho pequeno. Não use gradientes pesados.

---
Dica: se usar Midjourney / DALL-E / Ideogram, use o prompt acima como "description" e peça "high quality, flat design, clean typography, blue tech palette".
